# **App Name**: EduSearch Pro

## Core Features:

- Question Search: Search for questions by year, subject, and keywords.
- Question Details: View detailed information and metadata for each question.
- Practice Test: Let the user take a practice test for the selected question, so the system can remember which concepts and topics the user is familiar with, and which ones need attention.
- Weakness Analysis: Analyze the user's weaknesses based on their test answers.
- Personalized Recommendations: Based on the tool's analysis of user weaknesses, provide a curated list of similar questions.

## Style Guidelines:

- Primary color: Deep blue (#31486A) to convey knowledge and trust.
- Background color: Light gray (#F0F4F7) for a clean and academic feel.
- Accent color: Soft gray-blue (#708FA7) for interactive elements.
- Body and headline font: 'Literata', a transitional serif with a literary feel.
- Use clean, academic icons related to subjects, topics and question types.
- A clean, organized layout with a focus on readability and ease of navigation.
- Subtle transitions and animations to enhance the user experience.
